INSTRUKCJA URUCHOMIENIA LOKALNIE
================================================================================

WYMAGANIA:
----------
- Python 3.8+
- PyTorch
- torchvision
- matplotlib
- Pillow
- opencv-python   (odszumianie)
- pdf2image       (obsługa plików PDF)
- numpy

INSTALACJA ZALEŻNOŚCI:
----------------------
Otwórz terminal/cmd i wpisz:

    pip install torch torchvision matplotlib pillow opencv-python pdf2image numpy

Lub jeśli masz GPU NVIDIA (szybsze trenowanie):

    pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
    pip install matplotlib pillow opencv-python pdf2image numpy


================================================================================
JAK URUCHOMIĆ
================================================================================

KROK 1: Otwórz terminal w folderze projektu
-------------------------------------------
    cd C:\Users\User\Desktop\OCR_ZPI


KROK 2: Pobranie i przygotowanie danych
----------------------------------------
    python run_local.py --prepare

    To pobierze dataset Chars74K (~25 MB) i rozpakuje go.


KROK 3: Wytrenowanie modelu
----------------------------
    python run_local.py --train --epochs 10

    Trenowanie na CPU może potrwać. Na GPU będzie szybciej.
    Model zostanie zapisany do pliku: model_ocr.pth

    Dodatkowe opcje trenowania:
    python run_local.py --train --epochs 20 --batch-size 64
    python run_local.py --train --resume checkpoint.pth      (wznowienie treningu)


KROK 3b: Nieskończony trening (opcjonalnie)
--------------------------------------------
    python run_local.py --infinite

    Trening będzie kontynuowany do momentu przerwania (Ctrl+C).
    Checkpointy zapisywane są automatycznie co 5 epok (domyślnie).

    Przykłady:
    python run_local.py --infinite --checkpoint-interval 10
    python run_local.py --infinite --batch-size 64 --resume checkpoint.pth


KROK 4: Rozpoznanie własnego zdjęcia
--------------------------------------
    python run_local.py --image sciezka/do/zdjecia.png

    Przykłady:
    python run_local.py --image C:\Users\User\Desktop\litera_A.png
    python run_local.py --image ./test_images/znak.jpg
    python run_local.py -i moje_zdjecie.png


================================================================================
ODSZUMIANIE (opcjonalne)
================================================================================

Aby włączyć odszumianie obrazu przed rozpoznawaniem, dodaj flagę --denoise:

    python run_local.py --image test_A.png --denoise

Używany jest filtr bilateralny, który:
- Skutecznie redukuje szum
- Zachowuje krawędzie liter (ważne dla OCR)
- Nie wymaga dodatkowej konfiguracji

Odszumianie działa ze wszystkimi trybami rozpoznawania:
    python run_local.py --image litera.png --denoise
    python run_local.py --word napis.png --denoise
    python run_local.py --lines tekst.png --denoise

Uwaga: Podgląd obrazu w oknie wizualizacji pokazuje obraz po odszumianiu.


================================================================================
WSZYSTKIE OPCJE
================================================================================

    python run_local.py --help

  TRYBY DZIAŁANIA (wybierz jeden):
    --prepare, -p          Tylko pobierz i przygotuj dane
    --train, -t            Trenuj model przez określoną liczbę epok
    --infinite             Nieskończony trening (zatrzymaj przez Ctrl+C)
    --image, -i   PLIK     Rozpoznaj pojedynczą literę
    --word, -w    PLIK     Rozpoznaj wyraz (jedna linia tekstu)
    --lines, -l   PLIK     Rozpoznaj tekst wieloliniowy
    --multi, -m   PLIK...  Rozpoznaj wiele zdjęć pojedynczych liter

  PARAMETRY TRENOWANIA:
    --epochs, -e           Liczba epok trenowania (domyślnie 10)
    --batch-size, -b       Rozmiar batcha (domyślnie 32)
    --checkpoint-interval  Interwał zapisu checkpointów w trybie infinite (domyślnie 5)
    --resume, -r  PLIK     Wznów trening z pliku checkpointu (.pth)

  ODSZUMIANIE OBRAZU:
    --denoise              Włącz odszumianie (filtr bilateralny)

  FORMAT WYJŚCIA:
    --output, -o  PLIK     Ścieżka do pliku wyjściowego (txt/json)
    --output-format, -f    Format: console (domyślnie) | txt | json
    --quiet, -q            Cichy tryb – wyłącz wyświetlanie na konsoli

  PRZYKŁADY UŻYCIA:
    python run_local.py --image litera.png -f json      Zapis do folderu wynik/ jako JSON
    python run_local.py --word wyraz.png -f txt         Zapis do folderu wynik/ jako TXT
    python run_local.py --image litera.png -o moj_wynik.json   Własna ścieżka pliku
    python run_local.py --word wyraz.png -f json -q     Cichy tryb (tylko wynik)

Uwaga: opcje --prepare / --train / --infinite / --image / --word / --lines / --multi
       wykluczają się wzajemnie (tylko jedna na raz).


================================================================================
JAK DODAĆ WŁASNE ZDJĘCIE
================================================================================

1. PRZYGOTOWANIE ZDJĘCIA:
   - Zdjęcie powinno zawierać JEDEN znak (literę) dla trybu --image
   - Najlepiej na jasnym/białym tle
   - Formaty: PNG, JPG, JPEG, BMP, PDF
   - Dowolny rozmiar (zostanie przeskalowane do 48x48)

2. PRZYKŁADOWE ZDJĘCIA TESTOWE:
   Możesz stworzyć własne zdjęcia w programie Paint:
   - Otwórz Paint
   - Ustaw rozmiar obrazu np. 100x100 pikseli
   - Napisz jedną literę
   - Zapisz jako PNG

3. URUCHOMIENIE:
   python run_local.py --image nazwa_pliku.png

PROBLEM: "ModuleNotFoundError: No module named 'torch'"
ROZWIĄZANIE: pip install torch torchvision

PROBLEM: "ModuleNotFoundError: No module named 'cv2'"
ROZWIĄZANIE: pip install opencv-python

PROBLEM: "ModuleNotFoundError: No module named 'pdf2image'"
ROZWIĄZANIE: pip install pdf2image

PROBLEM: "No such file or directory"
ROZWIĄZANIE: Upewnij się, że jesteś w folderze OCR_ZPI
             cd C:\Users\User\Desktop\OCR_ZPI

PROBLEM: "UWAGA: Nie znaleziono modelu model_ocr.pth"
ROZWIĄZANIE: Najpierw wytrenuj model: python main.py --train

PROBLEM: Rozpoznawanie słabe/niepoprawne
ROZWIĄZANIE:
- Upewnij się, że zdjęcie zawiera tylko jeden znak
- Znak powinien być czytelny i na kontrastowym tle
- Wytrenuj model dłużej: python run_local.py --train --epochs 20
- Użyj nieskończonego treningu: python run_local.py --infinite
- Spróbuj odszumiania: python run_local.py --image plik.png --denoise
