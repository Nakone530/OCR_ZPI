3.5 TRENING MODELU
───────────────────────────────────────────────────────────────────────────────

  python run_local.py --train [opcje]

  Opcje treningu:
  • --epochs LICZBA       - Liczba epok (domyślnie: 10)
  • --batch-size ROZMIAR  - Rozmiar batcha (domyślnie: 32)
  • --resume PLIK         - Wznów trening z checkpointu

  Przykłady:
  • Trenuj model przez 20 epok:
    python run_local.py --train --epochs 20

  • Trenuj model z większym batchem:
    python run_local.py --train --epochs 15 --batch-size 64

  • Wznów trening z checkpointu:
    python run_local.py --train --resume checkpoint.pth


3.6 NIESKOŃCZONY TRENING (DO PRZERWANIA CTRL+C)
───────────────────────────────────────────────────────────────────────────────

  python run_local.py --infinite [opcje]

  Opcje:
  • --batch-size ROZMIAR       - Rozmiar batcha (domyślnie: 32)
  • --checkpoint-interval LICZBA - Co ile epok zapisywać checkpoint (domyślnie: 5)
  • --resume PLIK              - Wznów trening z checkpointu

  Przykłady:
  • Nieskończony trening z domyślnymi ustawieniami:
    python run_local.py --infinite

  • Nieskończony trening z większym batchem:
    python run_local.py --infinite --batch-size 64

  • Nieskończony trening ze checkpointem co 10 epok:
    python run_local.py --infinite --checkpoint-interval 10

9. ROZWIĄZYWANIE PROBLEMÓW
═══════════════════════════════════════════════════════════════════════════════

Problem: ModuleNotFoundError: No module named 'textual'
Rozwiązanie:
  pip install textual
  lub
  pip install -r requirements.txt

Problem: UWAGA: Nie znaleziono modelu ./model_ocr.pth
Rozwiązanie:
  - Najpierw wytrenuj model: python run_local.py --train
  - Lub użyj model z archiwum: python run_local.py --image obraz.png --model-path ./model_archive/model_20260330_124253.pth

Problem: Model nie istnieje: ./model_archive/model_XXXX.pth
Rozwiązanie:
  - Sprawdź nazwy modeli w folderze model_archive
  - Użyj pełną ścieżkę do modelu
  - W TUI wybierz model z dropdown zamiast ręcznego wpisywania

Problem: CUDA/GPU nie jest dostępny
Rozwiązanie:
  - Aplikacja automatycznie spadnie na CPU
  - Rozpoznawanie będzie wolniejsze, ale powinno działać poprawnie

Problem: Out of Memory (OOM) podczas treningu
Rozwiązanie:
  - Zmniejsz batch-size: --batch-size 16
  - Zmniejsz epochs: --epochs 5
  - Zabiłem procesy na GPU: nvidia-smi (Linux/WSL) lub Task Manager (Windows)
