================================================================================
INSTRUKCJA URUCHOMIENIA LOKALNIE
================================================================================

WYMAGANIA:
----------
- Python 3.8+
- PyTorch
- torchvision
- matplotlib
- Pillow

INSTALACJA ZALEŻNOŚCI:
----------------------
Otwórz terminal/cmd i wpisz:

    pip install torch torchvision matplotlib pillow

Lub jeśli masz GPU NVIDIA (szybsze trenowanie):

    pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118


================================================================================
JAK URUCHOMIĆ
================================================================================

KROK 1: Otwórz terminal w folderze projektu
-------------------------------------------
    cd C:\Users\User\Desktop\Czytanie


KROK 2: Pobranie i przygotowanie danych
--------------------------------
    python run_local.py --prepare

    To pobierze dataset Chars74K (~25 MB) i rozpakuje go.


KROK 3: Wytrenowanie modelu 
-------------------------------------------------
    python run_local.py --train --epochs 10

    Trenowanie na CPU może potrwać. Na GPU będzie szybciej.
    Model zostanie zapisany do pliku: model_ocr.pth


KROK 4: Rozpoznanie własnego zdjęcia
--------------------------------
    python run_local.py --image sciezka/do/zdjecia.png

    Przykłady:
    python run_local.py --image C:\Users\User\Desktop\litera_A.png
    python run_local.py --image ./test_images/znak.jpg
    python run_local.py -i moje_zdjecie.png


================================================================================
WSZYSTKIE OPCJE
================================================================================

    python run_local.py --help

    --prepare, -p     Tylko pobierz i przygotuj dane
    --train, -t       Trenuj model
    --epochs, -e      Liczba epok trenowania (domyślnie 10)
    --image, -i       Ścieżka do zdjęcia do rozpoznania


================================================================================
JAK DODAĆ WŁASNE ZDJĘCIE
================================================================================

1. PRZYGOTOWANIE ZDJĘCIA:
   - Zdjęcie powinno zawierać JEDEN znak (literę lub cyfrę)
   - Najlepiej na jasnym/białym tle
   - Formaty: PNG, JPG, JPEG, BMP
   - Dowolny rozmiar (zostanie przeskalowane do 48x48)

2. PRZYKŁADOWE ZDJĘCIA TESTOWE:
   Możesz stworzyć własne zdjęcia w programie Paint:
   - Otwórz Paint
   - Ustaw rozmiar obrazu np. 100x100 pikseli
   - Napisz jedną literę lub cyfrę
   - Zapisz jako PNG

3. URUCHOMIENIE:
   python run_local.py --image nazwa_pliku.png

================================================================================
ROZWIĄZYWANIE PROBLEMÓW
================================================================================

PROBLEM: "ModuleNotFoundError: No module named 'torch'"
ROZWIĄZANIE: pip install torch torchvision

PROBLEM: "No such file or directory"
ROZWIĄZANIE: Upewnij się, że jesteś w folderze Czytanie
             cd C:\Users\User\Desktop\Czytanie

PROBLEM: "UWAGA: Nie znaleziono modelu model_ocr.pth"
ROZWIĄZANIE: Najpierw wytrenuj model: python run_local.py --train

PROBLEM: Rozpoznawanie słabe/niepoprawne
ROZWIĄZANIE:
- Upewnij się, że zdjęcie zawiera tylko jeden znak
- Znak powinien być czytelny i na kontrastowym tle
- Wytrenuj model dłużej: python run_local.py --train --epochs 20
