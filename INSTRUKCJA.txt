================================================================================
ODSZUMIANIE (opcjonalne)
================================================================================

Włączenie odszumiania:
----------------------
Dodaj flagę:
    --denoise

Wybór metody:
-------------
    --denoise-method {nlm-color, median, bilateral, gaussian}
    (domyślnie: nlm-color)

Dodatkowe parametry:
--------------------
    --h       (int, domyślnie 10)     siła NLM dla luminancji (nlm-color)
    --hColor  (int, domyślnie 10)     siła NLM dla kolorów (nlm-color)
    --ksize   (int, domyślnie 3)      rozmiar jądra dla median/gaussian (3,5,7,...)

Przykłady użycia:
-----------------
1) NLM dla koloru (polecane jako start):
    python main.py --image test_A.png --denoise --denoise-method nlm-color --h 12 --hColor 12

2) Median (gdy masz szum „sól i pieprz"):
    python main.py --image test_A.png --denoise --denoise-method median --ksize 5

3) Bilateral (dobry kompromis: odszumia i zachowuje krawędzie):
    python main.py --image test_A.png --denoise --denoise-method bilateral

4) Gaussian (delikatne wygładzenie):
    python main.py --image test_A.png --denoise --denoise-method gaussian --ksize 5

Uwaga:
------
- Odszumianie działa także z trybami:
    --word  (rozpoznanie wyrazu)
    --lines (rozpoznanie linii/tekstu)
  Wystarczy dodać flagi jak wyżej, np.:
    python main.py --word napis.png --denoise --denoise-method nlm-color

- Podgląd obrazu w wynikowym oknie (wizualizacja) pokazuje obraz po odszumianiu,
  jeśli --denoise było włączone.


================================================================================
WSZYSTKIE OPCJE
================================================================================

    python main.py --help

    --prepare, -p          Tylko pobierz i przygotuj dane
    --train, -t            Trenuj model
    --epochs, -e           Liczba epok trenowania (domyślnie 10)
    --image, -i   PLIK     Rozpoznaj pojedynczą literę
    --word, -w    PLIK     Rozpoznaj wyraz (jedna linia tekstu)
    --lines, -l   PLIK     Rozpoznaj tekst wieloliniowy
    --multi, -m   PLIK...  Rozpoznaj wiele zdjęć pojedynczych liter

    --denoise              Włącz odszumianie wejścia
    --denoise-method       Metoda: nlm-color | median | bilateral | gaussian
    --h                    Siła NLM – luminancja
    --hColor               Siła NLM – kolor
    --ksize                Rozmiar jądra (median/gaussian): 3, 5, 7, ...

Uwaga: opcje --prepare / --train / --image / --word / --lines / --multi
       wykluczają się wzajemnie (tylko jedna na raz).


================================================================================
JAK DODAĆ WŁASNE ZDJĘCIE
================================================================================

1. PRZYGOTOWANIE ZDJĘCIA:
   - Zdjęcie powinno zawierać JEDEN znak (literę) dla trybu --image
   - Najlepiej na jasnym/białym tle
   - Formaty: PNG, JPG, JPEG, BMP, PDF
   - Dowolny rozmiar (zostanie przeskalowane do 48x48)

2. PRZYKŁADOWE ZDJĘCIA TESTOWE:
   Możesz stworzyć własne zdjęcia w programie Paint:
   - Otwórz Paint
   - Ustaw rozmiar obrazu np. 100x100 pikseli
   - Napisz jedną literę
   - Zapisz jako PNG

3. URUCHOMIENIE:
   python main.py --image nazwa_pliku.png

- Wytrenuj model dłużej: python main.py --train --epochs 20
- Spróbuj odszumiania: python main.py --image plik.png --denoise
