================================================================================
INSTRUKCJA URUCHOMIENIA LOKALNIE
================================================================================

WYMAGANIA:
----------
- Python 3.8+
- PyTorch
- torchvision
- matplotlib
- Pillow

INSTALACJA ZALEŻNOŚCI:
----------------------
Otwórz terminal/cmd i wpisz:

    pip install torch torchvision matplotlib pillow

Lub jeśli masz GPU NVIDIA (szybsze trenowanie):

    pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118


================================================================================
JAK URUCHOMIĆ
================================================================================

KROK 1: Otwórz terminal w folderze projektu
-------------------------------------------
    cd C:\Users\User\Desktop\Czytanie


KROK 2: Pobranie i przygotowanie danych
--------------------------------
    python run_local.py --prepare

    To pobierze dataset Chars74K (~25 MB) i rozpakuje go.


KROK 3: Wytrenowanie modelu 
-------------------------------------------------
    python run_local.py --train --epochs 10

    Trenowanie na CPU może potrwać. Na GPU będzie szybciej.
    Model zostanie zapisany do pliku: model_ocr.pth


KROK 3c: Zarządzanie archiwami modeli (opcjonalnie)
----------------------------------------------------
    Podczas treningu modele są automatycznie archiwizowane do folderu ./model_archive/
    Ostatnie 10 modeli jest zachowywane, starsze są automatycznie usuwane.

    Wylistuj wszystkie zarchiwizowane modele:
    python manage_models.py list

    Czyszczenie - zachowaj tylko N ostatnich modeli:
    python manage_models.py cleanup 5

    Ręczna archiwizacja modelu:
    python manage_models.py archive ./model_ocr.pth 92.50 50

    Przywrócenie modelu z archiwum:
    python manage_models.py restore model_20260330_143022.pth ./model_ocr.pth


KROK 4: Rozpoznanie własnego zdjęcia
--------------------------------
    python run_local.py --image sciezka/do/zdjecia.png

    Przykłady:
    python run_local.py --image C:\Users\User\Desktop\litera_A.png
    python run_local.py --image ./test_images/znak.jpg
    python run_local.py -i moje_zdjecie.png

================================================================================
ODSZUMIANIE (opcjonalne)
================================================================================

Włączenie odszumiania:
----------------------
Dodaj flagę:
    --denoise

Wybór metody:
-------------
    --denoise-method {nlm-color, median, bilateral, gaussian}
    (domyślnie: nlm-color)

Dodatkowe parametry:
--------------------
    --h       (int, domyślnie 10)     siła NLM dla luminancji (nlm-color)
    --hColor  (int, domyślnie 10)     siła NLM dla kolorów (nlm-color)
    --ksize   (int, domyślnie 3)      rozmiar jądra dla median/gaussian (3,5,7,...)

Przykłady użycia:
-----------------
1) NLM dla koloru (polecane jako start):
    python run_local.py --image test_A.png --denoise --denoise-method nlm-color --h 12 --hColor 12

2) Median (gdy masz szum „sól i pieprz”):
    python run_local.py --image test_A.png --denoise --denoise-method median --ksize 5

3) Bilateral (dobry kompromis: odszumia i zachowuje krawędzie):
    python run_local.py --image test_A.png --denoise --denoise-method bilateral

4) Gaussian (delikatne wygładzenie):
    python run_local.py --image test_A.png --denoise --denoise-method gaussian --ksize 5

Uwaga:
------
- Odszumianie działa także z trybami:
    --word  (rozpoznanie wyrazu)
    --lines (rozpoznanie linii/tekstu)
  Wystarczy dodać flagi jak wyżej, np.:
    python run_local.py --word napis.png --denoise --denoise-method nlm-color

- Podgląd obrazu w wynikowym oknie (visualizacja) pokazuje obraz po odszumianiu,
  jeśli --denoise było włączone.

================================================================================
JAK DODAĆ WŁASNE ZDJĘCIE
================================================================================

1. PRZYGOTOWANIE ZDJĘCIA:
   - Zdjęcie powinno zawierać JEDEN znak (literę lub cyfrę)
   - Najlepiej na jasnym/białym tle
   - Formaty: PNG, JPG, JPEG, BMP
   - Dowolny rozmiar (zostanie przeskalowane do 48x48)

2. PRZYKŁADOWE ZDJĘCIA TESTOWE:
   Możesz stworzyć własne zdjęcia w programie Paint:
   - Otwórz Paint
   - Ustaw rozmiar obrazu np. 100x100 pikseli
   - Napisz jedną literę lub cyfrę
   - Zapisz jako PNG

3. URUCHOMIENIE:
   python run_local.py --image nazwa_pliku.png

================================================================================
ROZWIĄZYWANIE PROBLEMÓW
================================================================================

PROBLEM: "ModuleNotFoundError: No module named 'torch'"
ROZWIĄZANIE: pip install torch torchvision

PROBLEM: "No such file or directory"
ROZWIĄZANIE: Upewnij się, że jesteś w folderze Czytanie
             cd C:\Users\User\Desktop\Czytanie

PROBLEM: "UWAGA: Nie znaleziono modelu model_ocr.pth"
ROZWIĄZANIE: Najpierw wytrenuj model: python run_local.py --train

PROBLEM: Rozpoznawanie słabe/niepoprawne
ROZWIĄZANIE:
- Upewnij się, że zdjęcie zawiera tylko jeden znak
- Znak powinien być czytelny i na kontrastowym tle
- Wytrenuj model dłużej: python run_local.py --train --epochs 20

PROBLEM: "Zbyt dużo archiwów modeli na dysku"
ROZWIĄZANIE:
- Wylistuj archiwa: python manage_models.py list
- Czyszczenie archiwów (zachowaj 5 ostatnich):
  python manage_models.py cleanup 5
- Domyślnie system automatycznie przechowuje ostatnie 10 modeli

PROBLEM: "Chcę przywrócić starszy model"
ROZWIĄZANIE:
- Wylistuj dostępne modele: python manage_models.py list
- Przywróć wybrany model:
  python manage_models.py restore model_YYYYMMDD_HHMMSS.pth ./model_ocr.pth
